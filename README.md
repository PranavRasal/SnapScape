# 📸 SnapScape

A modern blogging platform built with **React**, **Appwrite**, and **Redux Toolkit**, allowing users to create, manage, and share rich blog content with a clean and responsive user experience.


## 📖 Overview

SnapScape is a full-featured blogging application designed to provide a seamless content creation and reading experience.

Users can:

* Create and publish blog posts
* Edit and update existing content
* Delete posts
* Authenticate securely
* Manage personal content
* Browse articles from other users
* Access a responsive and intuitive interface

The project leverages Appwrite as a Backend-as-a-Service (BaaS) solution for authentication, database management, and storage, reducing backend complexity while maintaining scalability. Appwrite provides authentication, database, and storage services used by the application.

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/PranavRasal/SnapScape.git
cd SnapScape/mega-blog-with-appWrite
```

### Install Dependencies

```bash
npm install
```

### Configure Environment Variables

Create a `.env` file in the project root:

```env
VITE_APPWRITE_URL=
VITE_APPWRITE_PROJECT_ID=
VITE_APPWRITE_DATABASE_ID=
VITE_APPWRITE_COLLECTION_ID=
VITE_APPWRITE_BUCKET_ID=
```

## ▶️ Run Locally

### Development
